功能
1.隔空上下滑动

2.远程手势操作，张开鼠标移动，握拳鼠标左键按下


技术实现：
YOLOv8 + 自定义分类模型
一、使用 YOLOv8/YOLOv5 实现手部位置检测（目标框）
目标： 输出手部的矩形框（x,y,w,h,confidence）

工具链：

使用现有数据集训练手部检测模型

导出为 ONNX → 转为 NCNN 在 Android 运行

使用 CameraX 实现预览 + 推理

数据集：

EgoHands Dataset（手部边界框）


识别“张开手”或“握拳”：分类或图像特征分析
轻量分类模型（推荐）
在手部检测之后，裁剪出手部图像

输入到一个轻量分类模型（如 MobileNet）：
类别：open_hand, fist
训练自己的一小批数据（1000 张左右即可），转为 TFLite 或 ONNX
模型非常小，推理很快，适合移动端
